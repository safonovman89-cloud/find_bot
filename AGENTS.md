# Руководство для агентов разработки

## Назначение проекта

Проект реализует поискового бота `@findinfobot` для мессенджера MAX. Пользователь отправляет ключевые слова, бот одновременно ищет по всем подключённым базам знаний ЯНАО и возвращает до пяти наиболее релевантных результатов со ссылками на оригиналы.

## Источники данных

- `rsed` — полка РСЭД ЯНАО на `instructions.yanao.ru`;
- `esku` — книга ГИС ЕСКУ на `apbook.yanao.int`;
- `kb` — публичная база знаний `kb.yanao.ru`;
- `files` — документы из публичной папки `files.yanao.ru`.

Индексатор BookStack обходит книги и страницы. Индексатор общей папки читает дерево через WebDAV и извлекает текст из PDF, DOC/DOCX, PPTX, XLSX, ODT, RTF, TXT и Markdown. Видео, архивы и исполняемые файлы не скачиваются. Не увеличивайте лимит размера документов без оценки сетевой нагрузки и места на диске.

## Архитектура

- `bot/app.py` — FastAPI-приложение и endpoint `/webhook`;
- `bot/cli.py` — команды `index`, `polling` и `set-webhook`;
- `bot/indexer.py` — загрузка и разбор источников;
- `bot/search.py` — нормализация запросов и ранжирование;
- `bot/service.py` — обработка событий MAX и формирование ответов;
- `bot/max_api.py` — асинхронный клиент MAX Bot API;
- `bot/ai.py` — необязательный анализ контекста через AI Gateway ЯНАО с безопасным локальным fallback;
- `bot/storage.py` — SQLite-индекс, состояние и дедупликация событий;
- `deploy/` — unit-файлы systemd;
- `tests/` — автоматические тесты.

## Локальная разработка

Используйте Python 3.11+ и виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m bot.cli index
python -m pytest -q
```

Для проверки без публичного домена:

```bash
set -a; source .env; set +a
python -m bot.cli polling
```

Long Polling разрешён только для разработки и временной эксплуатации. Для production используйте HTTPS webhook на порту 443 с доверенным сертификатом.

## Обязательные проверки перед изменениями

1. Запустить `python -m compileall -q bot`.
2. Запустить `python -m pytest -q`.
3. При изменении индексатора выполнить `python -m bot.cli index` и проверить ненулевое количество документов для каждого источника.
4. При изменении обработки сообщений проверить, что итоговый текст не превышает лимит MAX в 4000 символов.
5. Не превышать ограничение MAX API в 30 запросов в секунду и два сообщения в секунду в один диалог.

## Безопасность

- Никогда не коммитьте `.env`, токен MAX, webhook-secret, SQLite-базу или пользовательские данные.
- Не выводите токены в логи и сообщения об ошибках.
- Не отключайте TLS-проверку. Клиент намеренно использует системное хранилище доверенных сертификатов.
- Проверяйте `X-Max-Bot-Api-Secret` для webhook.
- Не добавляйте закрытые источники без явного разрешения владельца проекта.
- История запросов хранится не более 7 дней и ограничена 40 сообщениями на диалог; не увеличивайте срок без явного требования и оценки обработки персональных данных.
- Сохраняйте ссылки на оригиналы, не публикуйте содержимое документов в репозитории.

## Эксплуатация

Пользовательская служба `findinfobot.service` включена через systemd с `Linger=yes`. После изменения кода перезапустите её:

```bash
systemctl --user restart findinfobot.service
systemctl --user status findinfobot.service
journalctl --user -u findinfobot.service -n 100 --no-pager
```

Индекс следует обновлять регулярно. Повторный проход использует ETag документов и не скачивает неизменившиеся файлы повторно.
