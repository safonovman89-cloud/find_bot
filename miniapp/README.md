# Мини-приложение «База знаний ЯНАО»

Мобильный поисковый интерфейс для бота MAX. Приложение ищет по РСЭД, ГИС ЕСКУ, базе знаний и документам ЯНАО, сохраняет контекст системы и локальную историю запросов.

## Разработка

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Перед публикацией обновите безопасный поисковый индекс из корня проекта и выполните проверки:

```bash
python3 scripts/export_miniapp_index.py
cd miniapp
npm run lint
npm test
```

Публичный индекс содержит только источник, заголовок, URL и хешированную сигнатуру слов. Полные тексты документов в веб-приложение не экспортируются.

## MAX

В `app/layout.tsx` подключён официальный MAX Bridge. Результаты открываются через `window.WebApp.openLink`, а вне MAX используется обычная новая вкладка.

После публикации вставьте HTTPS-адрес в поле «Мини-приложение» в настройках бота и выберите подпись кнопки «Открыть».

## GitHub Pages

Публичный адрес мини-приложения: <https://safonovman89-cloud.github.io/find_bot/>.

Команда `npm run build:pages` создаёт переносимый статический сайт в `pages-dist/`. Все пути относительные, поэтому приложение работает как на корневом домене, так и в подкаталоге репозитория GitHub Pages.

Workflow `.github/workflows/deploy-miniapp-pages.yml` собирает и публикует приложение при изменениях в ветке `main`. В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.
